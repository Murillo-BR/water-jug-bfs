Water Jug Problem

An interactive demonstration of Breadth-First Search (BFS). Set two jug capacities and a target amount, then find the shortest sequence of filling, emptying, and pouring operations.

Problem settings

Each state is (water in A, water in B). The goal is to obtain exactly the target amount in either jug. Both start empty.

    How it works

    BFS explores states in increasing order of the number of operations. It uses a queue to track unexplored states and a visited set to avoid repetitions. The six allowed operations are: fill A, fill B, empty A, empty B, pour A into B, and pour B into A.

    Because each operation costs one move, the first goal state found yields a shortest path. The algorithm reconstructs the exact sequence by following the previous-state links.
